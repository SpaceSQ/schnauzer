# Schnauzer Robot

S2 Schnauzer（广州雪纳瑞机器人）公开区。

本目录绑定 [github.com/SpaceSQ/schnauzer](https://github.com/SpaceSQ/schnauzer)，只存放脱敏后的展示端代码、日报/周报与 Wiki 文稿。

- `index.html` — schnauzer.robot0.com 脱敏首页（Vercel 生产部署从此目录发布）
- `src/` — 展示端源码占位
- 首次上线：在本目录执行 `npx vercel --prod`（项目已绑定域名，缺的是生产 Deployment）
- `reports/` — 经评估脱敏后的每日动态与每周进展
- `wiki/` — 同步至 GitHub Wiki 的公开知识库

绝密底座、研究目标与真犬孪生原始数据不在本仓库。
